# AI-Powered Lecture-to-Notes Generation Using Whisper, LSTM, and Natural Language Processing

## Introduction

This project presents an AI-based academic platform that automatically converts lecture videos into structured study notes using Whisper AI, LSTM deep learning models, and Natural Language Processing techniques. The system is designed to reduce manual note-taking efforts and improve learning efficiency by generating organized and revision-friendly academic notes from educational lectures.

---

## Features

- YouTube lecture video processing
- Speech-to-text transcription using Whisper AI
- LSTM-based note generation and summarization
- NLP-based text cleaning and structuring
- Structured markdown notes generation
- Flashcard generation
- Quiz generation
- Revision workspace
- Analytics dashboard
- Dark and Light mode support
- AI-powered academic assistant
